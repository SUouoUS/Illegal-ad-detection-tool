# ClearWeb 사용설명서

## 결과 파일 위치 (먼저 확인)
| 파일 | 위치 | 생성 조건 |
|---|---|---|
| `result.json` (적격평가용, 필수 4종) | 프로그램 폴더(개발 환경에서는 저장소 최상위 폴더) | 검사가 끝날 때마다 항상. 탐지 0건·중단·페이지 로딩 실패여도 생성 |
| `result_extra.json` (추가 탐지: 이미지 속 글자) | `result.json`과 같은 폴더 | '이미지 속 글자 검사'를 켜고 OCR이 실제로 실행된 경우에만 |
| 검사 기록(화면용) | `runs/<검사시각>/scan.json`, 이미지 미리보기 `runs/<검사시각>/images/` | 검사마다 |

환경 변수 `CLEARWEB_RESULT_DIR`로 결과 폴더를 바꿀 수 있습니다.
※ 이미지 검사를 끈 채 검사하면 `result_extra.json`은 새로 쓰지 않습니다. 같은 폴더에 이전 파일이 있으면 그대로 남으므로 제출 전에 확인하세요.

## 설치 (개발 환경, Windows 11)
```
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
.venv\Scripts\python -m playwright install chromium
```
Windows 실행 파일(배포 패키지)은 아직 준비 중입니다.

## 실행
- 화면: `.venv\Scripts\python -m clearweb` → 브라우저가 `http://127.0.0.1:8765/`로 열립니다.
- 화면 없이: `.venv\Scripts\python -m clearweb scan <주소> [--max-depth 2] [--max-pages 50] [--budget 1500] [--no-follow] [--ocr]`

## 화면 사용 순서
1. '점검할 웹 주소'에 주소를 넣고 '검사 시작'. 필요하면 '검사 설정'에서 깊이·최대 페이지 수·시간 한도·이미지 속 글자 검사를 바꿉니다.
2. 상태줄에서 진행(점검 페이지 수, 대기, 경과 시간)을 확인합니다. 실패나 한도 도달은 강조 표시됩니다.
3. '탐지 결과'에서 항목을 선택하면 오른쪽에 원문·복원 문구·광고로 의심한 이유·발견 위치가 나옵니다. '기술 상세'에 판단 근거와 선택자가 있습니다.
4. 이미지 검사를 켰다면 목록 아래 '이미지 속 글자'에 광고 의심·불확실 이미지가, '이미지 처리 내역'에 모든 이미지의 처리 결과와 실패·건너뜀 사유가 나옵니다.

## 이미지 속 글자 검사 (선택, 기본 꺼짐)
- 범위: **진입 페이지 한 개**의 `<img>` 요소만. 하위 페이지 이미지, CSS 배경 이미지, SVG, blob 주소, `<picture>`의 `<source>` 후보(img 요소의 주소만 사용), 동영상·애니메이션의 두 번째 이후 프레임, iframe 안 이미지는 검사하지 않습니다.
- 엔진: Windows 내장 OCR(Windows.Media.Ocr, 한국어 인식기). 외부 서버나 AI API를 쓰지 않고, 실행 중 모델을 내려받지 않습니다.
- 한국어 OCR 구성 요소가 없으면 화면에 '사용할 수 없음'과 설치 방법이 표시됩니다. 설치: 설정 > 시간 및 언어 > 언어 및 지역 > 한국어 > 언어 옵션 > '광학 문자 인식', 또는 관리자 PowerShell에서
  `Add-WindowsCapability -Online -Name "Language.OCR~~~ko-KR~0.0.1.0"`
- 판정: 이미지 한 장 안의 **한 문구 영역**만으로 광고 기준을 충족하면 '광고 의심', 근거가 부족하면 '불확실'. 이미지 결과는 확정 판정이 아니며, OCR 추출문은 원문이 아닙니다.
- 제출 파일: '광고 의심'만 `result_extra.json`에 `technique: "ETC"`, `extra_finding: "IMAGE_TEXT_AD(이미지 속 광고 의심 문구)"`로 기록합니다. `result.json`에는 넣지 않습니다.
- 기본 한도: 이미지 40장, 파일 8MB, 4천만 화소, 긴 변 2400px 초과 시 축소, 700px 미만은 2배 확대, 내려받기 8초, 이미지 검사 전체 90초.
