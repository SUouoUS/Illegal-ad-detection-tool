# 주최 측 확인 요청 — location 기준

## 질문
숨김 스타일이 **광고 문구만 담은 상위 요소**에 적용되어 있을 때, `location`으로 어느 요소를 기재해야 정답으로 인정되는지 확인 부탁드립니다.

```html
<div class="post-body">
  <p>시스템 점검으로 예약이 일시 중단됩니다.</p>
  <div class="legacy" style="display:none">
    <p>(광고 문구)</p>
  </div>
</div>
```

1. 이 경우 정답 `location`은 다음 중 무엇입니까?
   - (가) 숨김 스타일이 적용된 상위 요소: `div.post-body > div.legacy`
   - (나) 광고 문구를 담은 요소: `div.legacy > p`
   - (다) 둘 다 정답으로 인정
2. 같은 원칙이 `opacity:0`, `color:transparent`, `font-size:0`, 화면 밖 배치(`position:absolute; left:-9999px`)처럼 상위 요소에 적용된 다른 은닉 기법에도 똑같이 적용됩니까?
3. 상위 요소 안에 광고 문구 요소가 여러 개(예: `<p>` 두 개가 합쳐서 광고 한 건) 있을 때는 상위 요소 1건으로 기재합니까, 문구 요소마다 기재합니까?

## 배경
- 모집요강 붙임4는 `location`을 "웹페이지에서 불법광고가 검출된 요소의 위치"로 정의하고, 예시 `div.notice-board > span.visually-hidden`을 듭니다. 예시는 숨김이 적용된 요소와 문구를 담은 요소가 같아서 위 경우를 구분하지 못합니다.
- 같은 광고를 상위·하위 두 건으로 모두 제출하면 한 건은 오탐이 되므로, 기준을 확인한 뒤 한 가지로 기재하려 합니다.

## 현재 도구의 처리(확인 전 가정)
- (가)를 사용: 숨김 스타일을 가진 상위 요소가 광고 문구만 담고 있으면 그 상위 요소를 기재(`docs/SPEC_NOTES.md` 가정 2). 상위 요소에 다른 내용이 섞여 있으면 광고 문구를 담은 최소 요소를 기재.
- 자체 평가 사이트(`testsites/eval`)의 정답은 공식 문장("검출된 요소") 기준으로 (나)를 사용해 두었으며, 이 차이로 누락 1건·오탐 1건이 발생함. 답변을 받기 전에는 어느 쪽도 점수에 맞춰 바꾸지 않음.
