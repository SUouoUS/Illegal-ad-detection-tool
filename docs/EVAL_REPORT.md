### 독립성 한계
- 평가 사이트를 탐지기와 **같은 개발 과정(같은 작성자)** 에서 만들었음. 탐지 코드와 기존 테스트 사이트를 보지 않는 별도 에이전트에게 공식 규격만 주고 작성시키려 했으나, 가짜 광고 문구 작성 단계에서 콘텐츠 정책으로 중단되어 직접 작성함.
- 따라서 **완전히 독립된 평가가 아님.** 작성자가 탐지 규칙을 알고 있어 결과가 실제보다 좋게 나올 수 있음. 반대로 위치 규칙처럼 해석이 갈리는 부분은 공식 규격 문장 기준으로 정해 탐지기와 다르게 둔 사례도 있음.
- 모든 광고 문구·연락처·코드는 가짜 테스트 데이터(가짜 핸들, `.test` 도메인). `.test` 도메인은 실제 광고와 달라 연락 수단 인식에 불리하게 작용했을 수 있음(아래 누락 3).

## 5. 배포 전 반드시 고칠 문제 (우선순위)
1. **경로 방식 목록 쪽 이동의 깊이 계산** — `list-2.html`, `/page/2/` 같은 경로형 페이지 이동을 쿼리형과 같이 옆 이동으로 보지 않아 깊은 게시글을 놓침(누락 1). 탐지가 아니라 탐색 단계의 누락이라 영향이 큼.
2. **숨김 스타일이 감싸는 요소에 있을 때의 위치 기준** — 탐지기는 감싸는 요소, 평가 정답은 문구 요소로 보아 누락+오탐이 동시에 생김(누락 2·오탐 1). 공식 규격이 명확하지 않으므로 기준을 정하고(주최 측 문의 또는 실제 예시 확인), 어느 쪽이든 결과 문서에 근거를 남겨야 함.
3. **숨겨진 문구의 광고성 판단 어휘 부족** — 주제어는 있으나 유도 표현·연락 수단이 규칙 목록 밖(입장·실시간, 목록에 없는 최상위 도메인)이면 놓침(누락 3). 규칙을 넓힐 때는 dev·fp·실제 사이트 오탐을 함께 다시 확인해야 함.
4. **숫자 대체 복원** — 단어 끝·앞의 숫자 대체(c4sin0)를 복원하지 못함(누락 4).
- OCR: 오인식('파워불')에 대한 대응이 없음. 자모 분해 이미지는 지원하지 못함. OCR은 선택 기능이며 공식 결과에 영향 없음.

## 6. 재실행 방법
```
python -m testsites.server --site eval --port 8851
python -m clearweb scan http://127.0.0.1:8851/
python tools/score.py --answers testsites/eval/answers.json --result result.json --base http://127.0.0.1:8851/

python -m testsites.server --site eval_ocr --port 8861
python -m clearweb scan http://127.0.0.1:8861/ --no-follow --ocr
python tools/score_ocr.py --expected testsites/eval_ocr/expected.json
```
이 평가 자료는 이번 결과를 보고 규칙 수정에 사용하면 더 이상 평가용이 아니므로, 수정 후에는 새 평가 자료가 필요함.
