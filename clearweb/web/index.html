                  웹페이지에 숨겨지거나 변형된 광고 의심 문구를 찾아 위치와 근거를 보여주는 점검 도구입니다.

                  사용 순서

                  1. 웹 주소를 입력하고 ‘검사 시작’을 누릅니다.
                  2. 왼쪽 탐지 결과에서 항목을 선택합니다.
                  3. 오른쪽에서 원문, 복원 문구, 의심한 이유, 발견 위치를 확인합니다.

                  검사 범위

                  • 입력한 주소와 같은 사이트 안의 하위 페이지, 페이지에 삽입된 프레임을 검사합니다.
                  • 기본으로 입력한 페이지에서 링크를 두 번 따라간 곳까지, 최대 50페이지, 25분 동안 검사합니다. ‘검사 설정’에서 바꿀 수 있습니다.
                  • 이미지 속 글자는 ‘검사 설정’에서 이미지 속 글자 검사를 켜야 검사합니다. 결과는 ‘추가 의심 광고’에 표시되며 확정 판정이 아닙니다.
                  • 다른 사이트 링크, 로그인·글쓰기·삭제 같은 동작은 실행하지 않습니다.

                  결과를 볼 때

                  • ‘점검 실패’나 ‘일부 실패’는 페이지를 불러오지 못했다는 뜻이며, 광고가 없다는 뜻이 아닙니다.
                  • 결과 파일(result.json)은 프로그램 폴더에 자동 저장됩니다. 경로와 제외된 링크 수는 ‘검사 상세’에서 확인합니다.

                  투명 텍스트

                  화면 밖 은닉
                  문구를 화면 밖으로 옮기거나 아주 작게 만들고, 표시되지 않도록 숨기는 방식입니다.예시: 화면 왼쪽 멀리 배치하거나 글자 크기를 1px로 설정한 경우

                  숨김이나 문자 변형 자체가 불법광고를 의미하지는 않습니다. ClearWeb은 광고 의심 문맥을 함께 분석합니다.
